# Manufacturing

Resources for producing OpenVario hardware: bills of materials, schematics,
PCB data, case mechanics, and display variants.

Large binary assets stay on the project FTP archive. This section indexes them
and maps variants to current firmware image names.

## Contents

- [Bill of materials](bill-of-materials.md)
- [Schematics and PCB](schematics-and-pcb.md)
- [Variants](variants.md)
- [Mechanics](mechanics.md)

## Where files live

| Resource | Location |
|----------|----------|
| BOM spreadsheets | [ftp.openvario.org](https://ftp.openvario.org/) root |
| Schematics | [schematics.tar.gz](https://ftp.openvario.org/schematics.tar.gz) |
| Sensorboard CAD | [Sensorboard.zip](https://ftp.openvario.org/Sensorboard.zip) |
| FreeCAD model | [OV_Flight_Computer.FCStd](https://ftp.openvario.org/OV_Flight_Computer.FCStd) |
| Mechanics | [mechanics/](https://ftp.openvario.org/mechanics/) and [mechanics.tar.gz](https://ftp.openvario.org/mechanics.tar.gz) |
| Per-variant CAD | [variants/](https://ftp.openvario.org/variants/) |
| Current firmware | [GitHub Releases](https://github.com/Openvario/OpenVario/releases) |

## Limitations

Raspberry Pi CM4 mechanical and manufacturing packages are not published on the
FTP archive. CM4 software images for CH57 and PQ70 are available from GitHub
(see [Variants](variants.md)).
