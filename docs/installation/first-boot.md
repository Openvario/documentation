# First boot

Calibrate the touchscreen and set display rotation before flight.

## OVMenu

1. Apply power.
2. Press **Esc** during the progress bar.
3. If Esc is not pressed, the default flight application starts.

Navigation: **Up** / **Down**, **Enter**, **Esc** / **F1**. A USB keyboard
may be used for these keys before touch calibration is complete.

## Touch calibration

In XCSoar: **Config → Configuration → System Tools → Touchscreen calibration**
([System Services and Tools](../user-guide/system-services-and-tools.md)).

Or via OVMenu:

1. **Esc** → **System** → **Calibrate Touch**.
2. Touch each crosshair target.
3. Set display rotation again (below) so calibration remains valid.

## Display rotation

Four mounting orientations are supported (screen and touch).

1. OVMenu → **System** → **Settings** → **Display Rotation**.
2. Select orientation and reboot.
