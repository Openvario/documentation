# User guide

Operation of the OpenVario device: boot menu, network, file transfer, system
services, connectors, and hardware options. Flight features of XCSoar and
OpenSoar are documented in those projects’ manuals.

## Important notices

OpenVario with XCSoar/OpenSoar is a **VFR navigation aid** only. It is not a
substitute for traffic awareness or terrain warning.

Before flight: [First boot](../installation/first-boot.md),
[Hardware options](hardware-options.md).
