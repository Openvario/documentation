# OVMenu

Text boot menu. Press **Esc** during the progress bar. If Esc is not pressed,
the default flight application starts.

| Key | Action |
|-----|--------|
| Up / Down | Move selection |
| Enter | Confirm |
| Esc / F1 | Back / cancel |

| Entry | Purpose |
|-------|---------|
| Start XCSoar (or application selector) | Flight application |
| File copy | Maps, airspace, Flarmnet, waypoints, IGC via USB |
| System | Touch, rotation, map/system update, settings |
| Exit to shell | Linux shell |
| Restart / Power off | Reboot / shutdown |

Menu labels vary by image. Release 5.1.0 adds OpenSoar and a split system menu —
[release notes](../../release_notes/release_510.tex).
